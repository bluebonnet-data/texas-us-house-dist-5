## PROJECT 1: `Voter Targeting Dashboard`

### Project Context, Overview, & Goals

> How would you explain this project simply, from a big picture perspective? What is the context and why does this project need to be completed? Are there measurable objectives, or specific things you want to be able to do once this project is complete?

Given the characteristics of their district, the campaign is relying on voter turnout, rather than persuasion, to reach its vote goal. Because affordability is one of its key issues, the campaign is especially interested in targeting renters, young families (especially moms), and blue collar workers. Additionally, this district has been recently redrawn and now includesmore young voters who might be amenable to the campaign. The campaign, has done some targeting using L2 Data, and furth support in this area is needed. The candidate expressed an interest in haveing a voter targeting dashboard built for this purpose. Also, the campaign is in need of a way to consistently and accurately record which voters it has already contacted.


### Key Deliverable(s)

> What is the goal state? A document, an automation, a chart, etc…?

A voter targeting dashboard that makes the campaign's voter targets clearly visible and track progress toward its voter turnout goals.


### Existing Work & Stakeholders

>  Who will the fellows be working with? What should they know about what's already been done?

The campaign has no dedicated staff. Fellows would be working either directly with the candidate or with designated "super volunteers".

### Timeline

1. When you would want this project completed: *ASAP*
2. Any key dates or deadlines: *The (D) Primary runoff election will be held on May 26, 2026*
3. A few milestones to set within the project: *The campaign anticipates more access to organizations likely to support her campaign after the runoff, but not before*

### Data Sources and Tools

Please list all the datasets & other things needed for the project, and how/where this data can be accessed by the Fellows.

- L2 Data
- ECanvasser
- Google Data Studio (or similar) and connected data hosting (such as GCP)
